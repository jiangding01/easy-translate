## 1. 设计理念与视觉方向

### 1.1 原则（按冲突时的优先级排序）

1. **译文第一，界面隐身。** 用户来是为了读懂内容，不是来看扩展。凡出现在网页上的东西，都要先回答“它是否在抢原网页的注意力”。页内译文继承宿主字体，扩展自己的 chrome（外壳 UI）尽量小、尽量低饱和。
2. **零配置可用，配置渐进可见。** 默认 Google 端点开箱即用；LLM、术语表、Prompt 风格只在 Options 里出现，Popup 只放“此刻、此站”会用的控制项。
3. **每个状态都有出口。** 加载有进度，出错有一键恢复（重试 / 去设置 / 换引擎），离线有自动续传。不出现没有操作按钮的错误。
4. **键盘与鼠标同等。** 所有高频动作都有快捷键，快捷键直接写在按钮上（Raycast 式 key hint），不必另学。
5. **克制的精致。** 精致靠排版、间距、1px 边框和准确的状态，不靠渐变、插画和动效。

### 1.2 视觉方向

一句话：**“墨青纸感”**。中性暖灰的纸面，加一抹低饱和墨青色做唯一强调色；1px 发丝边框加轻阴影，密度接近 Linear，留白接近 Things。注入网页的组件看起来像浏览器原生的一部分，不像贴上去的广告。

### 1.3 参考产品与取舍

| 产品 | 取 | 舍 |
|---|---|---|
| **Linear** | 高信息密度下的秩序感：13px 正文、1px 低对比边框、克制的强调色、键盘优先 | 紫色品牌色和大面积暗色营销视觉 |
| **Raycast** | 紧凑浮层卡片、按钮右侧的快捷键提示 `⌥A`、行内操作 | 命令面板交互（翻译场景不需要搜索命令） |
| **Things 3** | 大留白、排版层级清楚、设置页像一封信一样平静 | 拟物的勾选动效 |
| **Apple HIG** | 系统字体栈、44pt→我们取 28px 最小点击区、Reduce Motion、材质层级（背景/表面/浮层） | 毛玻璃（`backdrop-filter` 在任意网页上性能和可读性都不可控） |
| **沉浸式翻译** | 段落级双语对照模型、悬浮球入口、输入框三连空格触发 | 设置项爆炸、页内多处入口、会员推销与角标 |
| **DeepL** | 划词卡片只做一件事：译文大而清楚，原文退后 | 大尺寸卡片与品牌化 Header |
| **Readwise Reader** | 阅读面板的逐句高亮跟随、“回到当前位置”胶囊 | 复杂的标注体系 |

## 2. 设计 Token

所有 token 以 `--et-` 为前缀，在 Shadow Root 的 `:host` 与扩展页面的 `:root` 上各定义一份（同一份 TS 源生成）。暗色通过 `[data-et-theme="dark"]` 切换；`system` 模式下读取 `prefers-color-scheme`。**注入 UI 的主题跟随浏览器系统设置，不跟随宿主网页**（宿主亮暗只影响页内译文样式，见 3.5）。

### 2.1 色彩

**品牌主色：墨青 Ink Teal `#2B6E6A`。** 选择理由：网页上最常见的强调色是蓝（链接）、红（警示）、紫（AI 产品），墨青与这三类都拉开色相，又因为饱和度只有约 44%，放在任何网页上都不刺眼；白字放在主色上的对比度为 5.9:1。

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--et-color-primary` | `#2B6E6A` | `#5FB3A9` | 主按钮、选中态、进度、焦点环 |
| `--et-color-primary-hover` | `#245D5A` | `#78C2B9` | 主色悬停 |
| `--et-color-primary-soft` | `#E6F0EE` | `#1C3532` | 选中行背景、Chip 背景 |
| `--et-color-on-primary` | `#FFFFFF` | `#0E1F1D` | 主色上的文字 |
| `--et-color-bg` | `#FFFFFF` | `#141517` | 页面 / 浮层底色 |
| `--et-color-surface` | `#F7F7F5` | `#1C1D20` | 分组背景、输入框底 |
| `--et-color-elevated` | `#FFFFFF` | `#232428` | 卡片、菜单（暗色靠提亮区分层级） |
| `--et-color-border` | `#E6E6E3` | `#2E3034` | 1px 分隔与描边 |
| `--et-color-border-strong` | `#D2D2CE` | `#3D4045` | 输入框描边、悬停描边 |
| `--et-color-text` | `#1C1D1F` | `#ECEDEE` | 主文字（对比度 16.8 / 15.9） |
| `--et-color-text-secondary` | `#5E6166` | `#A1A4AA` | 原文、说明文字（6.2 / 7.4） |
| `--et-color-text-tertiary` | `#8A8D93` | `#6E7177` | 时间戳、占位符，仅用于非关键信息与 ≥12px 的文字 |
| `--et-color-success` | `#2E7D4F` | `#5BC48A` | 连接测试通过、完成 |
| `--et-color-warning` | `#A86200` | `#E3A447` | 限流、降级、部分失败 |
| `--et-color-danger` | `#C4352B` | `#F07167` | 错误、密钥无效 |
| `--et-color-danger-soft` | `#FBECEA` | `#3A1F1D` | 错误行内块背景 |
| `--et-color-focus` | `#2B6E6A` | `#5FB3A9` | 焦点环（2px，外偏移 2px） |
| `--et-color-scrim` | `rgba(20,21,23,.32)` | `rgba(0,0,0,.56)` | 仅 Options 中的模态弹窗使用 |
| `--et-subtitle-bg` | `rgba(8,8,8,.72)` | 同左 | 字幕底（不随主题变化） |

信息色（info）一律使用主色，不另设蓝色。

### 2.2 字体与字号

**字体栈（不打包任何 Web Font）：**
```
--et-font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
                "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
--et-font-mono: ui-monospace, "SF Mono", Menlo, Consolas, monospace;
```

**注入 UI（Shadow DOM）：一律用 px，禁止 rem/em。** 宿主可能把 `html { font-size: 10px }` 或 62.5%，用 rem 会失控。

| Token | 值 | 行高 | 用途 |
|---|---|---|---|
| `--et-fs-inject-xs` | 11px | 16px | 快捷键提示、角标 |
| `--et-fs-inject-sm` | 12px | 18px | 原文、元信息、按钮 |
| `--et-fs-inject-md` | 13px | 20px | 卡片正文默认值 |
| `--et-fs-inject-lg` | 15px | 24px | 划词卡片译文（主内容） |
| `--et-fs-inject-xl` | 17px | 26px | 面板文章模式正文 |

**扩展页面（Popup / Options / Onboarding）：** 根字号 14px，可用 rem。

| Token | 值 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `--et-fs-page-xs` | 12px | 16px | 400 | 说明、表单提示 |
| `--et-fs-page-sm` | 13px | 20px | 400 | 次要文字、Popup 正文 |
| `--et-fs-page-md` | 14px | 22px | 400 | 默认正文 |
| `--et-fs-page-lg` | 16px | 24px | 600 | 分组标题 |
| `--et-fs-page-xl` | 20px | 28px | 600 | 页面标题 |
| `--et-fs-page-2xl` | 24px | 32px | 600 | 仅 Onboarding 主标题 |

字重只用 400 / 500 / 600 三档；500 用于按钮与选中项。中英混排不加 `letter-spacing`。

### 2.3 间距（4px 网格）

`--et-space-1: 4px` · `-2: 8px` · `-3: 12px` · `-4: 16px` · `-5: 20px` · `-6: 24px` · `-8: 32px` · `-10: 40px`

约定：组件内边距 8/12px；卡片内边距 12px（注入）/ 16px（扩展页）；分组间距 24px；Options 区块间距 32px。最小点击区 28×28px（注入 UI）/ 32×32px（扩展页）。

### 2.4 圆角

`--et-radius-xs: 4px`（Chip、kbd）· `-sm: 6px`（按钮、输入框、字幕底）· `-md: 8px`（菜单、Popup 内分组）· `-lg: 12px`（划词卡片、面板、Toast）· `-full: 999px`（悬浮球、胶囊）。嵌套元素的圆角 = 外层圆角 − 内边距，最小 4px。

### 2.5 阴影层级

| Token | 亮色 | 暗色 |
|---|---|---|
| `--et-shadow-1`（按钮悬停、悬浮球） | `0 1px 2px rgba(16,24,40,.06), 0 0 0 1px rgba(16,24,40,.06)` | `0 0 0 1px rgba(255,255,255,.08)` |
| `--et-shadow-2`（菜单、Toast） | `0 4px 12px rgba(16,24,40,.08), 0 0 0 1px rgba(16,24,40,.06)` | `0 4px 12px rgba(0,0,0,.4), 0 0 0 1px rgba(255,255,255,.08)` |
| `--et-shadow-3`（划词卡片、面板） | `0 12px 32px rgba(16,24,40,.12), 0 0 0 1px rgba(16,24,40,.06)` | `0 12px 32px rgba(0,0,0,.5), 0 0 0 1px rgba(255,255,255,.1)` |

阴影里自带 1px 描边环，因此注入 UI 在纯白和纯黑宿主上都能看清边界。

### 2.6 动效

| Token | 值 | 场景 |
|---|---|---|
| `--et-dur-fast` | 120ms | 悬停、按下、透明度变化 |
| `--et-dur-base` | 180ms | 菜单、卡片出现（opacity + translateY 4px） |
| `--et-dur-slow` | 240ms | 侧边面板滑入 |
| `--et-ease-out` | `cubic-bezier(0.2, 0, 0, 1)` | 进入 |
| `--et-ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 退出（时长取进入的 2/3） |
| `--et-ease-spring` | `cubic-bezier(0.34, 1.36, 0.64, 1)`，280ms | 仅用于悬浮球拖动后的吸边 |

**明确不用动效的场景：**
- 页内译文插入：直接出现，不淡入（几百个段落同时做动画会掉帧，也会干扰阅读）。
- 字幕切换：硬切，与视频帧同步。
- 流式文本：逐 token 直接追加，不做打字机效果，也不加闪烁光标。
- 列表：不做错峰入场（stagger）。
- Popup 与 Options 路由切换：无过渡。
- 数字与进度：进度条只用 `transform: scaleX` 做 120ms 线性过渡，数字不做滚动动画。
- `prefers-reduced-motion: reduce` 时：所有位移归零，只保留 ≤120ms 的透明度变化；吸边改为直接定位。

## 3. 关键界面

### 3.1 Popup（宽 360px，高度自适应，最高 520px）

**信息结构**：站点状态 → 主操作 → 语言 → 显示 → 次要开关。只保留“此刻、此站”会用到的东西。

```
┌────────────────────────────────────────┐
│ ◆ Easy Translate                    ⚙  │ 44px 头部
├────────────────────────────────────────┤
│ medium.com · 检测到 English             │ 12px 次要文字
│ ┌────────────────────────────────────┐ │
│ │        翻译此页            ⌥A      │ │ 40px 主按钮
│ └────────────────────────────────────┘ │
│                                        │
│ 语言   English  →  简体中文 ▾          │
│ 显示   [ 双语 | 仅译文 ]               │ 分段控件
│ 样式   [▁][░][▔][ ]  下划线            │ 4 个 28px 色块
│ 引擎   Google 翻译 ▾                   │
├────────────────────────────────────────┤
│ ☐ 总是翻译此站      ☐ 本站隐藏悬浮球   │
└────────────────────────────────────────┘
```

**状态：**
- **未翻译**：主按钮为实心主色“翻译此页”。
- **翻译中**：主按钮变为描边按钮，内部 2px 进度条，文案“翻译中 42% · 取消”。
- **已翻译**：主按钮为描边按钮“显示原文 ⌥A”，下方出现 12px 文字“已译 186 段 · 3 段失败 [重试]”。
- **不可用页**（`chrome://`、Web Store、PDF 查看器）：主按钮禁用，文案“此页面不支持翻译”，其余控件仍可改全局设置。
- **引擎错误**：头部下方出现 danger-soft 条：“DeepSeek 密钥无效 [去设置] [改用 Google]”。
- **离线**：主按钮禁用并显示“离线中，恢复网络后可翻译”。

语言下拉支持输入过滤；源语言默认“自动检测”，不单独占一行。

### 3.2 Options（左侧导航 200px + 内容区最大宽度 680px，居中）

```
┌──────────────┬───────────────────────────────────────────┐
│ ◆ Easy       │ 翻译服务                                   │
│   Translate  │                                           │
│              │ 默认引擎                                   │
│ ● 通用       │ ┌───────────────────────────────────────┐ │
│ ○ 翻译服务   │ │ ◉ Google 翻译     免费 · 无需配置  ✓   │ │
│ ○ 专家与术语 │ │ ○ OpenAI          未配置        配置 › │ │
│              │ │ ○ DeepSeek        已连接 · 312ms  ⋯   │ │
│              │ │ ○ 自定义 (OpenAI 兼容)          添加 + │ │
│              │ └───────────────────────────────────────┘ │
│              │                                           │
│              │ DeepSeek                                  │
│              │ API Key   [•••••••••••••a3f9]  [显示]     │
│              │ 模型      [deepseek-chat ▾]               │
│              │ Base URL  [https://api.deepseek.com]      │
│              │ [ 测试连接 ]  ✓ 连接成功 · 312ms          │
│ ──────────── │                                           │
│ v1.0 · 快捷键│                                           │
└──────────────┴───────────────────────────────────────────┘
```

- **通用**：界面语言、目标语言、默认显示模式与样式、主题（跟随系统/亮/暗）、悬浮球开关与禁用站点列表、划词触发方式、输入翻译触发方式、快捷键（跳转 `chrome://extensions/shortcuts`）。
- **翻译服务**：Provider 列表 + 选中项的详情表单（同页展开，不跳二级页）。设置**自动保存**，输入框失焦后 600ms 内保存，并在右上角显示“已保存”（12px tertiary 文字，2s 后消失）。“测试连接”按钮的状态：空闲 → 加载中（按钮内 12px spinner，文字保持不变以防宽度跳动）→ 成功（success 色 + 延迟毫秒数）/ 失败（danger 色 + 一行原因 + “查看详情”折叠展示原始错误）。
- **专家与术语库**：上半部分是 Prompt 风格，以卡片网格展示 4 个预设（通用 / 技术文档 / 学术 / 口语）和“新建风格”；编辑使用等宽字体 textarea，提供 `{{source}} {{target}} {{text}}` 变量 Chip 点击插入。下半部分是术语表：两列表格（原词 → 译词），支持行内编辑，提供“导入 CSV/JSON”“导出”。导入前先展示预览（新增 n / 覆盖 m / 无效 k），确认后才写入。
- **空态**：术语表为空时显示一行说明“术语会在所有引擎中强制保持一致的译法”和两个按钮 [添加术语] [导入]，不放插画。

### 3.3 悬浮球

```
            网页右边缘 │
                   ╭───╮│
                   │ 译 ││   36×36，贴边 8px
                   ╰───╯│
  悬停展开 →  ┌─────────────╮
              │ 显示原文 ⌥A │
              │ 仅译文   ⌥W │
              │ 本站隐藏    │
              │ 设置        │
              └─────────────╯
```

- 尺寸 36px，`--et-color-elevated` 底 + `--et-shadow-1`，中间 16px 图标。默认位于右边缘、垂直 60% 处。
- **单击**：切换整页翻译。**拖动**：位移超过 4px 才算拖动（避免误触）；松手后吸附到最近的左/右边缘（spring 280ms），垂直位置限制在视口 10%–90%，全局记忆。
- **闲置**：3 秒无交互后透明度降为 0.6，并向边缘内收 50%（露出半个球）；鼠标接近 24px 范围内时恢复。
- **悬停 300ms** 展开菜单（最多 4 项，菜单项高 32px）；离开 200ms 后收起。
- **状态**（全部体现在球本身，不额外弹层）：
  - 翻译中：外圈 2px 进度环（主色）。
  - 完成：图标变实心，进度环 600ms 后淡出。
  - 部分失败：右上角 6px warning 圆点，菜单首项变为“重试 3 段失败”。
  - 引擎错误：6px danger 圆点，菜单首项变为“修复引擎设置”。
  - 离线：图标变 tertiary 灰色，title 提示“离线中，恢复后自动继续”。
- 全屏视频、`<dialog>` 打开、打印时自动隐藏。

### 3.4 划词翻译卡片（宽 360px，最高 420px，内容区滚动）

触发：选中文字松开鼠标后，在选区结束点右下方 8px 处出现 24px 的“译”小按钮（不直接弹卡片，避免打扰复制操作）；点击它或按 `⌥S` 打开卡片。设置中可改为“选中即翻译”。

```
┌──────────────────────────────────────────┐
│ English → 简体中文   [Google ▾]   📌  ✕   │ 36px，可拖动
├──────────────────────────────────────────┤
│ The quick brown fox jumps over the lazy  │ 12px secondary
│ dog and keeps running…         展开 ▾    │ 原文最多 2 行
│                                          │
│ 敏捷的棕色狐狸跳过了那只懒狗，并继续     │ 15px text
│ 奔跑。                                   │
├──────────────────────────────────────────┤
│ [⧉ 复制]  [🔊 朗读]            DeepSeek ⇄ │ 32px 工具栏
└──────────────────────────────────────────┘
```

- **定位**：优先放在选区下方，空间不足时放上方，水平方向夹在视口内 12px 安全边距以内。
- **固定**（📌）：卡片转为 `position: fixed`，不随页面滚动，点击外部不关闭；可同时固定最多 3 张，第 4 张会替换最早固定的那张。
- **未固定**：点击卡片外部或按 `Esc` 关闭。
- **切换引擎**：Header 的引擎 Chip 下拉。切换后原地重新翻译，保留卡片高度作为最小高度，防止抖动。
- **单词**（选区 ≤ 3 个词且引擎支持词典）：译文区改为“音标 + 词性 + 释义列表”，最多 4 条。
- **状态**：加载中显示 2 行骨架条（高 10px，surface 色，静态不闪烁）；LLM 引擎流式追加文本；错误显示“翻译失败：密钥无效 [去设置] [用 Google 重试]”；离线显示“离线中 [重试]”。
- 复制成功后按钮文案变为“已复制”1.5s，不弹 Toast。朗读使用 `speechSynthesis`，播放中图标变为 ■ 停止。

### 3.5 页内双语译文样式（4 种）

译文节点 `<et-tr>` 插在原文段落之后（块级），**继承宿主的字体、字号、颜色**，同时带 `lang="{目标语言}"` 和 `translate="no"` 属性。短文本（≤ 40 字符的链接、按钮、导航项）用行内模式：原文后加一个空格再接译文，不换行。

**宿主亮暗检测**：对每个翻译容器，自下而上查找第一个非透明 `background-color`（最多查 8 层，查不到则视为白色），计算相对亮度：L < 0.4 时在 `<et-tr>` 上设置 `data-et-host="dark"`。每个容器只计算一次并缓存。

| 样式 | 亮背景宿主 | 暗背景宿主 | 定义 |
|---|---|---|---|
| **无装饰** | 继承 | 继承 | `margin-top: .25em`，无其他样式 |
| **淡化** | 继承色 × `opacity: .72` | `opacity: .78` | 降低译文视觉权重，适合以原文为主的阅读 |
| **下划线**（默认） | `text-decoration: underline dotted 1px #2B6E6A99` | `#5FB3A999` | `text-underline-offset: .28em`；CJK 文本加 `text-decoration-skip-ink: none` |
| **高亮** | `background: #2B6E6A14` | `#5FB3A929` | `padding: .1em .25em; border-radius: 3px; box-decoration-break: clone` |

```
无装饰    The model is trained on public data.
          该模型基于公开数据训练。

淡化      The model is trained on public data.
          该模型基于公开数据训练。        ← 72% 不透明度

下划线    The model is trained on public data.
          该模型基于公开数据训练。
          ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄            ← 墨青点线

高亮      The model is trained on public data.
         ▐该模型基于公开数据训练。▌         ← 8% 墨青底
```

“仅译文”模式：原文节点加 `data-et-hidden` 并设为 `display:none`（保留在 DOM 中，可一键还原）。段落级失败时，在 `<et-tr>` 位置渲染一个行内 Chip：`⚠ 翻译失败 · 重试`（12px，danger 色文字，无背景，点击后只重试该段）。

### 3.6 输入翻译

- **触发**：在 `<input>`、`<textarea>`、`contenteditable` 中按 `⌥I`（默认）；「连按 3 次空格（间隔 ≤ 300ms）」为设置中的可选触发方式，默认关闭。在 Monaco、CodeMirror、带 `[data-et-ignore]` 的元素以及 `type=password` 中禁用。
- **目标语言**：独立设置项，默认 English（“我写中文，发出去英文”的场景）。

```
┌───────────────────────────────────────────┐
│ 这周五之前可以把报告发我吗          ⟳ 翻译中 │ ← 右上角 20px 胶囊
└───────────────────────────────────────────┘
                     ↓
┌───────────────────────────────────────────┐
│ Could you send me the report by Friday?   │
└───────────────────────────────────────────┘
  ╭──────────────────────────────╮
  │ 已翻译为 English · ⌘Z 撤销   │  ← 输入框下方 Toast，2.5s
  ╰──────────────────────────────╯
```

- 回填使用 `document.execCommand('insertText')`（不支持时用 `InputEvent` 兜底），这样原生 `⌘Z` 能撤销并恢复原文，也能触发 React/Vue 等框架的受控组件更新。
- 先删除末尾触发用的 3 个空格，再翻译。翻译期间输入框设为 `aria-busy="true"`；如果用户继续输入，取消本次翻译并静默丢弃结果。
- 失败时胶囊变为 danger 色：“翻译失败”，3s 后消失，原文保持不变。

### 3.7 YouTube 字幕覆盖层

```
┌──────────────────────── 播放器 ─────────────────────────┐
│                                                         │
│                                                         │
│          ┌───────────────────────────────────┐          │
│          │ and that's why we built it this way │ ← 原文 0.8×，#D8D8D8
│          │   这就是我们这样构建它的原因        │ ← 译文 1×，#FFFFFF
│          └───────────────────────────────────┘          │
│ ▶ ──●────────────  1:23 / 9:41      [译▾] CC ⚙ ⛶       │
└─────────────────────────────────────────────────────────┘
                                       └ 原文 / 译文 / 双语 / 阅读面板
```

- 隐藏 YouTube 原生字幕（`.ytp-caption-window-container { display:none }`），由我们统一渲染。
- **字号**：译文 = `clamp(14px, 播放器宽度 × 0.024, 34px)`；原文为译文的 0.8 倍。用 ResizeObserver 监听播放器尺寸。
- **位置**：底部居中，距底部 = 控制栏高度 + 12px；控制栏隐藏时下移到 48px。最多 2 行，宽度上限为播放器宽度的 80%。
- **背景**：`--et-subtitle-bg`，圆角 6px，内边距 4px 10px，文字 `text-shadow: 0 1px 2px rgba(0,0,0,.6)`。
- **控制**：在 YouTube 控制栏右侧插入“译”按钮（尺寸与原生按钮一致），菜单提供 原文 / 译文 / 双语 / 打开阅读面板。
- **广告**：检测到播放器带 `.ad-showing` 时整个覆盖层设为 `visibility:hidden`，广告结束后立即恢复。
- **状态**：译文未就绪的句子先只显示原文（不显示 loading）；翻译失败的句子降级为只显示原文，在面板中标记失败。无字幕的视频不插入“译”按钮。

### 3.8 字幕阅读 / 文章精翻面板

**决策：用页内 Shadow DOM 面板，不用 `chrome.sidePanel`。** 理由：与播放器的时间同步不需要跨进程消息，可以和字幕覆盖层共享状态，也不会切换 Chrome 的全局侧栏。面板覆盖在页面右侧（不挤压布局），默认宽 400px，可拖动左边缘在 320–560px 之间调整，从右侧滑入 240ms。

```
│▌       它在各方面都失败了。          │   + primary-soft 底
│                                      │
│ 01:23  So we rewrote the core.       │
```

**字幕模式**：逐句列表；点击任意一句跳转到对应时间并播放；当前句自动滚动到面板 1/3 高度处。用户手动滚动后暂停自动跟随，并显示“回到当前”胶囊。

**文章模式**（精翻）：用 LLM 把整段字幕或网页正文重组为段落，按块（每块约 800 token）流式生成。

```
│ ✓ 第 1 节 · 背景                     │ 完成：正文 17px
│   …                                  │
```

- 最多 2 个块并发；失败的块不阻塞后续块。每个块都有独立的“重试”；全部完成后，Header 显示“3 块失败 · 全部重试”。
- 完成后可以“复制全文”或“导出 Markdown”。
- **空态**：没有字幕时显示“此视频没有可用字幕”；非视频页的文章模式未提取到正文时，显示“未识别到正文 [选择区域翻译]”。
- 未配置 LLM 时，文章模式 Tab 仍可点击，内容区显示一句说明 + [配置 AI 引擎]，不置灰隐藏。

## 4. 关键流程

### 4.1 安装 → 第一次翻译（目标 ≤ 30 秒，零配置）

| 时间点 | 用户看到 | 系统行为 |
|---|---|---|
| 0s | 安装完成，欢迎页打开 | 读取 `navigator.language` 预填目标语言 |
| ≤1.5s | 示例段落出现译文 | Google 端点请求；失败时自动重试 1 次，再失败则显示“网络不可用，稍后自动重试” |
| ~10s | 点选样式，即时预览 | 写入 storage |
| ~15s | 回到原网页 / 打开外文页面 | 悬浮球出现 + 一次性气泡 |
| ~20s | 按 ⌥A 或点击球，首屏译文出现 | 首批请求只发视口内的段落 |

验收标准：在干净的 Chrome 配置下，3 名未看过本产品的测试者中，至少 2 人在 30 秒内完成第一次整页翻译，全程不需要阅读说明。

### 4.2 整页翻译进度反馈

- **视口优先**：先翻译视口内及下方 1 屏的段落（IntersectionObserver，`rootMargin: 0px 0px 100% 0px`），滚动时继续按需翻译。每批最多 20 段或 4000 字符。
- **页内不放占位**：译文到达时一次性插入，每段只发生一次布局变化（放占位符再替换会造成两次跳动）。
- **进度只放在悬浮球上**（进度环 = 已完成 / 已入队），Popup 中同步显示百分比。
- **LLM 引擎**：单段流式写入 `<et-tr>`，按每 50ms 合批一次写 DOM，减少重排。
- 首批译文的目标出现时间：Google ≤ 800ms，LLM 首个 token ≤ 1.5s。

### 4.3 出错恢复

| 类型 | 判定 | 表现 | 恢复 |
|---|---|---|---|
| **Provider 配置错误** | 401 / 403 / 密钥缺失 / 模型不存在 | 每个会话、每个 provider 只弹一次 Toast（右上角，360px，不自动消失）：“DeepSeek 密钥无效” | [去设置]（直达对应 provider 表单并聚焦出错字段）· [改用 Google 翻译]（本次会话临时切换） |
| **额度 / 限流** | 429 / quota | 球显示 warning 点；自动退避（1s、2s、4s、8s，最多 4 次）；持续 30s 以上才弹 Toast | 自动恢复；Toast 提供 [改用 Google] |
| **网络错误** | `navigator.onLine === false` 或 fetch 失败 | 球变灰色；队列暂停；不弹 Toast | 监听 `online` 事件后自动续传，无需操作 |
| **段落级失败** | 单段超时（Google 10s / LLM 30s）或解析失败 | 该段显示行内“翻译失败 · 重试”Chip | 单击重试该段；球菜单和 Popup 提供“重试全部失败（n）” |

错误文案统一用“发生了什么 + 怎么办”的格式，不直接显示状态码；原始错误放在 Options 连接测试的“查看详情”里。

### 4.4 快捷键一览

| 动作 | macOS | Windows / Linux | 作用域 |
|---|---|---|---|
| 整页翻译 / 显示原文 | `⌥A` | `Alt+A` | 全局（manifest commands） |
| 双语 / 仅译文切换 | `⌥W` | `Alt+W` | 全局（manifest commands） |
| 翻译选中文本 | `⌥S` | `Alt+S` | 全局（manifest commands） |
| 打开字幕阅读面板 | `⌥R` | `Alt+R` | YouTube 页（manifest commands） |
| 输入翻译 | 连按 3 次空格 / `⌥I` | 同左 / `Alt+I` | 输入框内（content script 监听） |
| 关闭卡片 / 面板 | `Esc` | `Esc` | 焦点在扩展 UI 内 |
| 卡片内复制译文 | `⌘C`（无选区时） | `Ctrl+C` | 卡片获焦时 |
| 面板上一句 / 下一句 | `↑` / `↓`，`Enter` 跳转播放 | 同左 | 面板获焦时 |

manifest `commands` 最多只能声明 4 个建议快捷键，正好对应前 4 项；其余由 content script 监听，并且只在焦点位于对应元素内时生效。所有快捷键都可以在 `chrome://extensions/shortcuts` 修改，Options 的“通用”页提供跳转链接。

## 5. 克制清单（不做什么）

1. **不做账号、登录、云同步**。设置存本地（`storage.local`），跨设备迁移用导入/导出文件。
2. **不在网页上放第二个常驻入口**：只有悬浮球，没有顶部工具栏、侧边 Tab 或角标。
3. **不做翻译统计、成就、字数报表**。
4. **不提供自定义配色或 CSS 编辑器**：只有 4 种样式 + 亮/暗/系统三种主题。
5. **Popup 中不放站点规则编辑器、Prompt 编辑或 Provider 表单**，这些只放在 Options。
6. **不打包 Web Font、图标字体或插画**：图标是 ≤ 24 个内联 SVG（单个 16px，1.5px 线宽），全部打包后 ≤ 6KB。
7. **不使用毛玻璃 / `backdrop-filter`、渐变按钮和品牌吉祥物**。
8. **同一时刻最多只有 1 个 Toast**，新的替换旧的；成功类操作不弹 Toast（复制、保存直接用行内反馈）。
9. **不做 AI 对话、总结、问答**。文章精翻是唯一的 LLM 长文本功能。
10. **不发出声音，不抢焦点**：卡片打开时不调用 `focus()`，焦点留在宿主页面，用户按 Tab 才进入卡片。
11. **不在扩展图标上显示数字角标**：只用一个 6px 状态点（翻译中为主色，出错为 danger 色）。
12. **Options 设置最多两层**：Options 没有超过 3 个路由，也没有“高级设置”折叠页。

## 6. 可访问性、隔离与性能

### 6.1 可访问性

- **对比度**：正文 ≥ 4.5:1，UI 控件与焦点环 ≥ 3:1（第 2.1 节的 HEX 已全部满足）。`text-tertiary` 只用于非关键信息。“淡化”样式下限为 0.72 不透明度，不再往下降。
- **键盘**：所有可点击元素都可用 Tab 到达；焦点环为 `outline: 2px solid var(--et-color-focus); outline-offset: 2px`，只在 `:focus-visible` 时显示。悬浮球支持 Tab 聚焦后按 `Enter` 翻译、按 `Space` 打开菜单、用方向键在菜单中移动。面板中焦点被困在面板内，`Esc` 关闭面板后焦点返回打开前的元素。
- **屏幕阅读器**：划词卡片使用 `role="dialog" aria-modal="false" aria-label="翻译结果"`；译文区域使用 `aria-live="polite"`（流式输出时只在完成后播报一次）。页内 `<et-tr>` 带 `lang` 属性，保证读屏用正确的语音朗读。字幕覆盖层设为 `aria-hidden="true"`（避免和播放器重复播报），阅读面板是它的可访问替代。悬浮球使用 `aria-label="翻译此页"`，并带有 `aria-pressed` 表示当前状态。
- **减少动效**：遵循 `prefers-reduced-motion`，见 2.6。
- **缩放**：扩展页面在 200% 缩放下不出现横向滚动；注入 UI 跟随浏览器页面缩放（px 会随 zoom 等比放大，符合预期）。

### 6.2 宿主样式隔离策略

- **注入 UI**：WXT `createShadowRootUi`，`cssInjectionMode: 'ui'`。`:host { all: initial; }` 之后重新声明字体、颜色和 `box-sizing: border-box`。只用 px；z-index 统一使用 `2147483000` 起的 10 个值（球 +1、卡片 +2、面板 +3、Toast +4）。所有挂载点 `position: fixed`，不受宿主 `transform` 祖先影响（挂到 `document.documentElement` 而不是 `body`）。
- **事件隔离**：卡片和面板内的 `keydown`、`keyup`、`keypress`、`wheel` 事件调用 `stopPropagation`，防止触发宿主快捷键（如 YouTube 的 `k`/`j`/`l`、GitHub 的 `s`）。
- **页内译文（非 Shadow DOM）**：使用自定义标签 `<et-tr>`（宿主的类选择器和标签选择器基本不会命中它）。样式用一张 `adoptedStyleSheets` 注入，选择器写成 `et-tr[data-et-s][data-et-s]` 来提高优先级；只设置 `display`、`margin`、`text-decoration`、`background`、`opacity` 这 5 类属性，其余全部继承宿主。宿主若用 `* {}` 或 `p > *` 覆盖了这些属性，再对这 5 个属性加 `!important`，并且仅限这 5 个。
- **不注入**到 `<pre>`、`<code>`、`<kbd>`、`[contenteditable]`、`[translate=no]`、`.notranslate` 中。

### 6.3 性能预算（CI 中用 size-limit 卡住）

| 项 | 预算（gzip） | 说明 |
|---|---|---|
| Content script 核心（DOM 遍历、插入、快捷键，**不含 React**） | ≤ 20KB JS | `document_idle` 注入，主线程执行 ≤ 10ms |
| 注入 UI 共享块（react + react-dom + 球） | ≤ 70KB JS | `requestIdleCallback` 后懒加载，悬浮球在页面 idle 后 300ms 内出现 |
| 划词卡片块 | ≤ 15KB JS | 选区 `mouseup` 时预加载；点击到卡片可见 ≤ 100ms |
